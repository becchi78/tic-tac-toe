# 要件定義書

## 目的 / 背景

ブラウザだけで遊べるマルバツ（3目並べ / tic-tac-toe）ゲームを提供する。
インストール不要・アカウント不要で、2人プレイと CPU 対戦の両方を楽しめる
シンプルな Web アプリを目指す。学習・デモ用途を兼ねる。

## スコープ

### 対象

- 3×3 盤面のマルバツゲーム（ローカル完結）
- 2人プレイ（同一画面で交互に着手）
- CPU 対戦（先手 / 後手、強さ 3 段階）
- 勝敗・引き分け判定と勝ちラインの強調表示
- 手番表示・スコア（X 勝 / O 勝 / 引き分け）記録
- 盤面リセット・スコアクリア
- キーボード操作とスクリーンリーダー対応
- 静的サイトとしてのビルド・配信（GitHub Pages 想定）

### 対象外

- オンライン対戦・通信対戦
- サーバーサイド・DB・認証
- 4×4 以上の可変盤面、ルール変種（misère 等）
- 対戦履歴の永続化（リロードで消えてよい）
- 多言語対応（日本語のみ）

## 非機能要件

- パフォーマンス: 初期表示 1s 以内（静的アセットのみ）。CPU 思考は hard でも 100ms 以内。
- セキュリティ: 外部通信なし。ユーザー入力の永続化なし。
- 可用性 / 運用: 静的ホスティングで完結。ビルド成果物は `app/dist`。
- アクセシビリティ: 各マスに `aria-label`、手番/結果は `aria-live` で通知。キーボードのみで全操作可能。
- レスポンシブ: スマートフォン縦画面〜デスクトップで崩れない。
- 対応ブラウザ: モダンブラウザ最新版（Chrome / Firefox / Safari / Edge）。

## 制約 / 前提

- 技術スタック（`CONTRIBUTING.md` に反映済み）: TypeScript / React / Vite / Vitest / ESLint + Prettier。
- パッケージマネージャ: npm。アプリ本体は `app/` サブディレクトリ。
- 外部依存: ランタイムの外部 API・CDN 依存を持たない。
